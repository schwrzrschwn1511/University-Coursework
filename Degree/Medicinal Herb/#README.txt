#README
Malaysia Medicinal Plants and Herbs Database System

1. Java files are in MalaysiaHerb -> src -> in folder ClassAll & malaysiaherb
2. Class files are in MalaysiaHerb -> build -> classes -> in folder ClassAll & malaysiaherb
3. .jar files is in MalaysiaHerb -> dist -> named MalaysiaHerb.jar
4. mysql-connector-j-8.3.0.jar is in MalaysiaHerb -> dist -> lib
5. We are using java JDK17
 

Instruction to run
1. Import malaysiaherbs.sql into database
2. Connect using jconnector
3. go to dist and write on console from there, java -jar "MalaysiaHerb.jar"
